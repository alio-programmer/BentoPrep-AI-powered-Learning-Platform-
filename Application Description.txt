# Build: AI-Powered DSA & Interview Preparation Platform

Build a production-quality web application that acts as a **one-stop AI tutor and interview preparation platform** for software engineering and technical interviews.

The application should combine:

1. DSA problem tracking
2. Personal solution/memory cards
3. Spaced-repetition revision
4. Personalized DSA roadmaps
5. AI-powered tutoring
6. Company-specific interview preparation
7. Coding interview simulation
8. CS fundamentals preparation
9. Resume/job-description analysis
10. Progress analytics

The goal is to help a developer go from their current skill level to being **interview-ready for a specific company and role**.

---

# 1. Product Vision

The application should feel like having a personal AI interview coach.

A user should be able to say:

> "I want to prepare for a Google Software Engineer interview in 60 days."

The application should analyze the user's current skills, available time, target role, target company, and previous performance and generate a personalized preparation plan.

For example:

### Day 1

* Arrays — Two Sum
* Arrays — Best Time to Buy and Sell Stock
* Learn: Hash Maps
* 20 min concept revision
* 10 min behavioral preparation

### Day 2

* Strings — Valid Anagram
* Hashing — Group Anagrams
* Review yesterday's mistakes

### Day 3

* Revision Day
* Reattempt Two Sum without looking at the solution
* AI-generated variations
* Mini quiz

### Day 4

* Sliding Window
* Longest Substring Without Repeating Characters
* AI explanation

The system should dynamically adjust the schedule based on performance.

# 4. Memory Cards

Every solved problem should automatically become a **DSA Memory Card**.

Example:

---

## Two Sum

**Pattern:** Hash Map

**Core Insight**

Store previously seen values and search for the complement.

**Mental Trigger**

> "Need to find two values satisfying a condition → think HashMap."

**Complexity**

O(n) time
O(n) space

**My Mistake**

Initially attempted nested loops.

**Remember**

Hashing allows constant-time average lookup.

---

The user should be able to review these cards later.

Cards should support:

* Flip animation
* Mark as remembered
* Mark as difficult
* Mark as forgotten
* Edit
* Add notes
* Add tags
* AI explanation
* AI-generated variation

# 5. Spaced Repetition Engine

Implement an intelligent revision system.

Do NOT simply schedule revision randomly.

Use spaced repetition principles.

For example:

Problem solved today:

Revision schedule:

* Day 1
* Day 3
* Day 7
* Day 14
* Day 30
* Day 60

But dynamically adjust this based on:

* Confidence
* Previous mistakes
* Number of failed attempts
* Time since last review
* Whether user remembered the solution
* Difficulty
* Performance history

If a user forgets a problem, decrease its interval and bring it back sooner.

Example:

User forgets "Binary Tree Maximum Path Sum."

System:

> You struggled with this problem twice. I'll bring it back tomorrow instead of next week.

# 7. Adaptive Roadmap

The roadmap must NOT be static.

If the user performs poorly on Graphs:

The AI should automatically increase graph-related problems.

If the user performs extremely well on Arrays:

Reduce repetition and allocate more time to weaker topics.

Example:

> Your Array performance is 87%, but Dynamic Programming is only 42%. I've reduced Array practice and increased DP sessions for the next 10 days.

Allow the user to manually override the AI plan.

### Socratic Mode

### Code Review Mode

Analyze the user's code.

### Interviewer Mode

Act like a real interviewer.

# 31. Critical Product Principle

The application should NOT simply track:

> "You solved 100 problems."

It should understand:

> "You solved 100 problems, but you repeatedly struggle with graph traversal and dynamic programming, forget problems after approximately 10 days, and often identify the correct approach but struggle with implementation."

Then it should act on that information.

The ultimate goal is:

**Track → Remember → Identify Weakness → Practice → Reassess → Adapt → Interview**

Build the product around this feedback loop.
